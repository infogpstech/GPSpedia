Banco local de calidad de miniaturas

Herramienta de medición para Beta. Las imágenes se procesan en este navegador: no se suben, no se envían a servicios externos y no se guardan en IndexedDB. Usa únicamente muestras sintéticas o autorizadas y anonimizadas.

Alcance: compara las variantes PNG de 300, 800 y 1600 px con la misma regla de escala de GPSpedia. Mide decodificación, Canvas, codificación, espera de cola, bytes y transparencia. La revisión de legibilidad sigue siendo visual.

Selecciona archivos JPEG, PNG o WebP. Para abrir desde el repositorio: python -m http.server 8000 y visita /JS/Tests/ThumbnailQualityBenchmark.html.
