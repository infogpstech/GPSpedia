2026-11-25 | Rectificación de análisis — semántica completed en proyección de útiles
- La hipótesis inicial de que CATALOG debía restablecer completed=false al recibir un nuevo event después de withdrawn fue incorrecta.

- El cambio experimental de CATALOG fue revertido; el blob volvió al contenido previo. Commit de reversión: 1ebe3e1ea26a8f3f095b15c98f45935c482fb817.
- Se conserva la prueba añadida para el caso event → withdrawn → event sin materialización previa; se ampliará cobertura para la secuencia completed → withdrawn → event y el contador base.
